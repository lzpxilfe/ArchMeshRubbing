# 석기 — 축이 없는 유물에 지금의 파이프라인을 대 보다

토기와 기와는 회전축 위에서 돈다. 석기는 아니다. 이 문서는 회전축을 전제로 만든 프로그램이 뗀석기를 만나면 어디까지 되고 어디서 멈추는지를 적는다. [`docs/REAL_DATA_TRIAL.md`](REAL_DATA_TRIAL.md)처럼 잘 된 것보다 걸린 것을 적는다.

## 지침이 말하는 것

공개 교재 두 권이 석기 실측을 다룬다([`docs/REFERENCES.md`](REFERENCES.md)).

- **[K1] 2013, pp. 45-49 (김동숙, "석기 및 금속류 실측법").** 용기류가 아닌 석기는 **눕혀 놓고** 실측한다. 기본은 **평면도**이고, **횡단면은 평면도 아래, 종단면은 평면도 오른쪽**에 둔다(횡단면이 평면 표현을 가리지 않으면 평면도 안쪽에 넣어도 좋다). 외곽은 5 mm 안팎 간격으로 측점을 내려 잇고, 외선 안쪽에 **내선**을 넣어야 입체감 있는 평면도가 된다. 단면은 평면도에서 자를 위치를 정해 바디를 뜬다.
- **[K2] 2014, p. 43 (양영주, "선사시대 석기의 실측법").** 정치는 **사용 방향**대로 — 석촉은 경부가 아래, 괭이는 신부가 아래. 평면도 + 종·횡단면이 가장 단순한 방식이지만 그것은 상하면이 대칭에 가까운 석촉·석부에 한하고, 이상적으로는 **제3각법으로 6면 투상도 전부**, 또는 입방체 전개도 배치다. 석검은 반드시 측면도, 석촉도 측면도를 권한다.

프로그램에 대입하면: 정치는 손으로(Align이 아니라 스캔 파일의 자세 그대로여도 된다), 6면 투상은 이미 있는 6뷰 외곽선, 단면은 이미 있는 자른 면, 내선은 **없다.**

## 합성 뗀석기

실제 석기 스캔은 못 구했다. 국립중앙박물관 3D 공개 데이터 134건을 12쪽 전부 훑었는데 석기는 한 점도 없다(석조여래좌상·지장보살좌상 같은 석조 조각뿐이고, 나머지는 자기·토기·금속·목제). `tests/synthetic_lithic.py`가 대신 잎 모양 양면석기를 만든다: 평면은 끝쪽으로 좁아지는 타원(84 × 50 mm), 등면은 평면 여섯 장의 상한(박리면이 평평하고 그 사이 능선이 날카롭다), 배면은 매끈한 한 면에 타격점 쪽 혹(bulb) 2.5 mm, 두 면이 가장자리에서 만나 날이 된다. 닫힌 다면체, 면 17,040, 결정적.

## 되는 것

`tests/test_lithic_trial.py`.

| | 결과 |
|---|---|
| 6뷰 외곽선(격자 0.01 mm) | 전부 조각 1, 구멍 0. 평면 넓이가 해석값과 0.2% 안에서 같다 |
| 종단면(x-z)·횡단면(y-z) | 각각 닫힌 고리 하나. 종단면의 배면이 타격점 쪽에서 1 mm 넘게 더 부풀어 있다(bulb) |
| 평면 + 종단면 + 횡단면 도판 (A4, 1:1) | 오프라인 검증기 통과 |

Align 없이 된다. 회전축을 요구하는 것은 미러 반입면·반단면과 중심축선뿐이고 석기는 둘 다 쓰지 않는다.

## 걸린 것

**날카로운 가장자리는 격자에 민감하다.** 토기는 0.25 mm에서도 그려졌는데, 이 석기는 옆에서 본 뷰가 격자에 따라 갈린다.

| 격자 | top | front | back | left | right |
|---|---|---|---|---|---|
| 0.1 mm | **거부** 격자 구멍 0.7×0.9 mm | ok | ok | ok | ok |
| 0.05 mm | ok | ok | ok | ok | **거부** 격자 구멍 0.5×0.2 mm |
| 0.02 mm | ok | ok | **거부** 조각 2(격자가 끊음) | ok | ok |
| 0.01 mm (기본값) | ok | ok | ok | ok | ok |

날이 모서리로 보이는 뷰에서는 가장자리의 삼각형이 격자보다 얇은 sliver로 투영되고, 그것이 사라진 자리에 구멍이 뚫리거나 끝이 끊긴다. 왼쪽·오른쪽이 같은 격자에서 다르게 나오는 것은 격자 원점이 뷰마다 달라서다. **거부는 전부 옳다** — outline 1.2.0의 조각 게이트와 1.3.0의 구멍 게이트가 잡은 것이고, 거부문이 그대로 "use a finer grid"를 말한다. 기본값 0.01 mm면 전부 통과한다. 다만 토기에서 굵은 격자로 시간을 아끼던 습관은 석기에 가져올 수 없다.

## 없는 것

1. **내선 — 박리면 능선.** 석기 도면의 핵심이다. 등면의 박리면이 서로 만나는 능선을 평면도 안에 그려야 어떻게 만들었는지가 보인다. 지금은 외곽선과 단면뿐이다. 합성 석기의 능선은 평면과 평면이 만나는 날카로운 모서리라 이면각으로 잡히겠지만, 실제 스캔의 능선은 둥글고 잡음이 섞여 문턱 하나로는 안 될 것이다 — 실제 석기 스캔 없이는 문턱을 정할 수 없다. 홈 검출(`annotation.groove`)이 오목한 주름을 잡는 것과 짝이 되는 볼록한 주름 검출이 필요하고, 새 record 종류·선 종류·sidecar 판이 따라온다.
2. **도판 배치.** 지침의 배치(횡단면은 평면 아래, 종단면은 오른쪽)를 composer가 모른다. 지금은 준 순서대로 왼쪽에서 오른쪽으로 놓는다.
3. **날의 표현.** 마연흔·타제조정흔·고타조정흔의 도면 표현([K2] 도면 2-5)은 그림으로만 있어 글로 옮길 규칙이 없다. 실제 도면을 보고 정해야 한다.
4. **실제 스캔.** 위 표의 격자 민감성이 실제 스캔(둥근 능선, 잡음)에서 어떻게 되는지 모른다.
